# Review a Reference Solution and restore the Starter

Start in the built-in Go / GoFrame Workspace after [restart proof](recent-workspace.md). Keep `task-api/main.go` open with the saved run marker.

1. Go to Exercise 1, **让一个请求完成往返**, and click **查看参考提示与 Diff** in the manual. Select `task-api/main.go` if needed. Capture the side-by-side diff with the marker on the Workspace side. Check that the file on disk still has the marker.
2. Click **应用 Reference Solution**. Compare the Workspace file byte for byte with `builtin-courses/go-goframe-practice/solutions/ex-1/task-api/main.go`.
3. With that file still open, click **对比 Starter 恢复** in the editor toolbar. Capture the Starter diff. Click **恢复此文件**, then compare the result with `builtin-courses/go-goframe-practice/starter/task-api/main.go`. Record both disk comparisons in the run's file assertions.
