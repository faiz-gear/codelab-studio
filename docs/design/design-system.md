## 1. 核心设计哲学

1. **单一入口与零压迫感（Calm & Progressive Disclosure）**：首页只保留一个居中 Arc 光晕主入口与紧凑 `2×2` 课程卡片；工作台默认仅展开「左步骤手册（① → ② → ③）+ 右宽裕编辑器与紧凑终端」两栏，项目文件树、辅助调试命令、思考题与 AI 助教默认收起、按需展开。
2. **纯中性画廊灰阶（`oklch(L% 0 0)`）**：浅色默认纯净白底（`100%` / `97.8%`），深色为独立调校的黑曜石灰（`19%` / `21.5%` / `24%`），彻底去除蓝灰偏色，让代码高亮与状态语义色自然浮现。
3. **默认克制单色 + 8 组强调色定制**：默认主按钮使用高反差单色（浅色深墨白字 `19.67:1` / 深色柔白深字 `16.44:1`）；点击顶栏「外观」滑出毛玻璃抽屉，实时切换 8 组 Arc 强调色（`neutral / violet / blue / green / amber / orange / coral / rose`）、浅/深主题、字号并支持一键复制主题 CSS。
4. **冷却粉彩语义族**：四语言徽章（Go→Sky、JS/TS→Amber、Python→Teal、Java→Rose）与成功/警告/失败/AI 状态统一采用 `color-mix(in oklab, var(--tone) var(--badge-tint), var(--surface))` 柔光配方。
5. **轻字重编辑感排版 + 临界阻尼动效**：展示标题使用 **Geist Medium（`500`，`-0.03em`）**，正文与控件使用 **Inter**，代码与数字使用 **JetBrains Mono + `tabular-nums`**；交互采用 `--ease-standard (cubic-bezier(.22,1,.36,1))` 与 `--ease-drawer (cubic-bezier(.32,.72,0,1))`，完整支持 `prefers-reduced-motion`。

## 3. 核心界面与渐进披露结构

| 界面 / 组件 | 视觉与布局规范 | 交互行为 |
|---|---|---|
| **极简桌面顶栏（48px）** | 仅 6 组轻控件：品牌、课程下拉 + 进度、环境点、专注切换（`⌘B`）、`AI 助教`、`外观`、`⚙` | 毛玻璃基底，窄屏零换行；窗口点静默灰，Hover 显色 |
| **首页（Welcome Home）** | 居中 `24px` 圆角 Arc 光晕 Hero（1 主按钮 + 1 次按钮）+ `2×2` 紧凑课程卡片 + 极简最近工作区 | 0.5 秒定位主入口，零统计墙与文字堆砌 |

## 4. 桌面端断点与无障碍

- **`≥ 1280px`**：默认两栏（35% / 65%）。AI 抽屉宽 `360px`；打开时自动收起文件树，编辑区保留约 `560px`，其余宽度分配给手册。手册最小宽 `320px`，拖拽不得挤占编辑区；双击分隔条复原。
- **`1280–1439px`**：三栏仍并排，手册内边距收为 `18px`，目标说明为 `13px`。手册与 AI 消息独立纵向滚动，输入框固定在抽屉底部。
- **`< 1280px`**：AI 抽屉转为右侧毛玻璃覆盖浮层；`⌘/Ctrl + B` 一键折叠手册进入专注编码态。
- **无障碍**：跳过导航链接、`:focus-visible` 双环聚焦态、`aria-live="polite"` 播报、`Esc` 关闭所有浮层、`prefers-reduced-motion` 自动降速。


## 5. B 方案定稿参数

用户选定 B「均衡紧凑」。保留中性灰阶、Arc 光晕与三步全展开；不引入 A 的 1280px 覆盖策略或 C 的单步折叠。

| 区域 | 定稿值 |
|---|---|
| 首页内容 | 最大宽 `1080px`；页边距 `24px 48px 40px`；区块间距 `24px` |
| Hero | 内边距 `26px 32px`；元素间距 `12px`；标题 `34px`；说明 `14px` |
| 课程卡片 | 两列；卡片间距 `12px`；内边距 `16px 20px`；内部间距 `9px` |
| 三步手册 | 默认内边距 `20px 22px 28px`；区块间距 `17px`；步骤内部间距 `8px` |
| 验收清单 | 卡片内边距 `12px`；条目间距 `7px`；条目内边距 `7px 9px` |
| 终端 | 默认高 `256px`，与已选 B 原型一致；可拖拽调节 |

原型通过 `../tokens.css` 读取共享令牌。AI 对话、ACP 审批与终端均为交互模拟。正式原型不包含临时比较稿的方案切换条，因此比比较截图多出 `42px` 可用高度。
